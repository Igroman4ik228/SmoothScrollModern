# Тестирование

## Запуск набора тестов

```powershell
dotnet test SmoothScrollModern.slnx
```

Тестовый проект `SmoothScrollModern.Application.Tests` использует xUnit. Команда восстанавливает зависимости, собирает решение и выполняет тесты.

## Что уже проверяется

| Область | Примеры поведения |
|---|---|
| Движок прокрутки | остановка инерции при отказе доставки, обработка дельт |
| Решение о прокрутке | включённость, пауза, полноэкранный режим и правила приложений |
| Конфигурация | построение снимков и публикация изменений |
| Правила приложений | нормализация, добавление и выбор правил |
| Интеграционные границы | поведение `InputInjectionService` через тестовые двойники |

## Как писать тесты

- Изолируйте `SmoothScrollEngine`, `ScrollDecisionService` и фабрики снимков от реальных окон и глобальных хуков.
- Подменяйте интерфейсы `IInputInjectionService`, `IWindowIdentityResolver` и другие адаптеры простыми test doubles.
- В тестах асинхронной физики ждите наблюдаемое событие с ограничением времени, а не используйте бессрочное ожидание.
- Название теста должно сообщать действие, ожидаемый результат и условие, например `EnqueueWheel_StopsInertiaWhenDeliveryIsRejected`.

## Ручная проверка

После изменений UI или интеграции с Windows запустите приложение и проверьте запуск, сохранение темы, правила приложений, паузу и завершение из трея, а также прокрутку в другом приложении.
