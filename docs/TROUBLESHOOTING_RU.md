# Диагностика

## Восстановление зависимостей или сборка не проходят

```powershell
dotnet restore SmoothScrollModern.slnx
dotnet build SmoothScrollModern.slnx
```

Проверьте, что установлен .NET SDK, совместимый с `net10.0-windows10.0.19041.0`, и команда выполняется в корне репозитория. Для подробностей добавьте обычную детализацию MSBuild:

```powershell
dotnet build SmoothScrollModern.slnx --verbosity normal
```

## Приложение не запускается

Убедитесь, что запускается WinUI-проект, а не библиотека:

```powershell
dotnet run --project SmoothScrollModern/SmoothScrollModern.csproj --configuration Debug
```

При исключении на старте приложение показывает сообщение Windows. Повторите запуск после успешной сборки и проверьте исключение, не меняя пользовательский файл настроек наугад.

## Прокрутка не сглаживается

Проверьте, включён ли главный переключатель, не активна ли временная пауза, не исключено ли полноэкранное окно автоматически и есть ли подходящее включённое правило для выбранного режима списка. Собственное окно SmoothScroll намеренно исключается из обработки.

## Повреждены настройки

Сервис JSON автоматически создаёт резервную копию с суффиксом `.bak` и продолжает с настройками по умолчанию. Используйте импорт ранее экспортированного JSON-файла, если нужно восстановить персональную конфигурацию.

## Нужна информация для отчёта об ошибке

Приложите версию Windows, вывод `dotnet --info`, команду, которая воспроизводит проблему, и текст исключения или ошибки сборки. Не публикуйте экспорт настроек, если в нём есть чувствительные пользовательские пути или названия программ.
