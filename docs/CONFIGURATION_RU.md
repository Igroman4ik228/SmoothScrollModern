# Конфигурация

## Где хранятся данные

Настройки сохраняются в JSON-файле:

```text
%AppData%\SmoothScroll\settings.json
```

При ошибке чтения приложение сохраняет повреждённый файл рядом с суффиксом `.yyyyMMddHHmmss.bak` и загружает валидные значения по умолчанию. Диагностика не должна изменять этот файл без явного согласия пользователя.

## Основные параметры

| Группа | Параметры |
|---|---|
| Включение | `IsEnabled`, автоматическое исключение полноэкранных приложений, режим списка приложений |
| Физика прокрутки | дистанция, трение, ускорение, затухание при смене направления, максимальная скорость и порог остановки |
| Точность | множитель точности, горизонтальная прокрутка и клавиши обхода |
| Профили | именованные пользовательские наборы параметров прокрутки |
| Правила приложений | процесс, путь исполняемого файла, включённость, режим доставки и профиль |
| Окно и трей | сворачивание в трей, запуск в трее и автозапуск с Windows |
| Оформление | `System`, `Light` или `Dark` |

Числовые параметры приводятся к разрешённым диапазонам и шагам при валидации. Не редактируйте JSON вручную во время работы приложения: используйте интерфейс или сначала закройте приложение.

## Правила приложений

- **Исключения:** сглаживание включено везде, кроме правил, где оно отключено.
- **Только выбранные приложения:** сглаживание работает лишь для включённых правил.

Правило по `ExecutablePath` точнее и проверяется раньше правила по `ProcessName`. Правила, которые приложение добавляет в интерфейсе, помечаются как пользовательские.

## Импорт и экспорт

В разделе настроек доступны экспорт текущих настроек в JSON и импорт из JSON. При импорте файл проходит валидацию; дублирующиеся имена профилей отклоняются.

## Переменные среды и конфигурация сборки

Приложение не использует обязательных переменных среды. Целевая платформа и пакеты заданы в файлах `.csproj`; сведения о запуске отладчика — в `SmoothScrollModern/Properties/launchSettings.json`.
