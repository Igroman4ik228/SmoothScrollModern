# Начало работы

## Требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 версии 1809 (17763) или новее |
| SDK | .NET SDK, совместимый с `net10.0-windows10.0.19041.0` |
| Среда | PowerShell или терминал Visual Studio |

Приложение использует WinUI 3 и Windows API, поэтому запуск на macOS и Linux не поддерживается.

## Сборка

Откройте корень рабочего дерева и выполните:

```powershell
dotnet restore SmoothScrollModern.slnx
dotnet build SmoothScrollModern.slnx
```

Успешная сборка завершается без ошибок и собирает четыре рабочих проекта и проект тестов.

## Первый запуск

```powershell
dotnet run --project SmoothScrollModern/SmoothScrollModern.csproj --configuration Debug
```

1. Откройте раздел настроек и убедитесь, что плавная прокрутка включена.
2. При необходимости настройте параметры профиля или добавьте исключение для процесса.
3. Перейдите в другое окно и прокрутите содержимое колёсиком мыши.
4. Для управления из фона используйте значок приложения в области уведомлений Windows.

## Проверка работы

По умолчанию правило для собственного процесса приложения исключает его из сглаживания. Проверяйте прокрутку в другом приложении с прокручиваемым содержимым. Если эффект не применяется, сначала проверьте режим списка приложений и правила — см. [конфигурацию](CONFIGURATION_RU.md).
