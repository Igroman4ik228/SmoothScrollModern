# SmoothScroll

> Нативное Windows-приложение, которое делает прокрутку колёсиком мыши плавной и управляемой для каждого приложения.

SmoothScroll перехватывает глобальный ввод колёсика, выбирает подходящий профиль для активного окна и отправляет сглаженные события прокрутки. Настройки, исключения и профили доступны в интерфейсе приложения и сохраняются локально.

[English version](README.md)

## Быстрый старт

В корне репозитория выполните:

```powershell
dotnet restore SmoothScrollModern.slnx
dotnet build SmoothScrollModern.slnx
dotnet run --project SmoothScrollModern/SmoothScrollModern.csproj --configuration Debug
```

После запуска откройте окно приложения или его значок в области уведомлений, включите плавную прокрутку и проверьте её в другом приложении.

## Возможности

- Глобальная плавная вертикальная и горизонтальная прокрутка.
- Настраиваемая физика: дистанция, трение, ускорение, ограничение скорости и точность.
- Профили прокрутки и правила для отдельных процессов или исполняемых файлов.
- Режимы исключений и «только выбранные приложения».
- Управление из системного трея, автозапуск и временная пауза.
- Импорт, экспорт и восстановление локальных настроек.

## Как это работает

```text
Колёсико мыши → глобальный хук → выбор правила для окна → движок сглаживания → Win32-событие колеса
```

Правило по пути исполняемого файла имеет приоритет над правилом по имени процесса. Полноэкранные приложения могут автоматически исключаться.
