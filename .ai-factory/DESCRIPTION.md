# SmoothScroll — описание проекта

## Назначение

SmoothScroll — Windows-приложение для плавной прокрутки мышью в сторонних приложениях. Оно получает глобальные события колёсика, сопоставляет активное окно с настройками пользователя и при необходимости доставляет сглаженный поток событий прокрутки через Windows API.

## Ключевые возможности

- Плавная вертикальная и горизонтальная прокрутка с настраиваемой физикой.
- Глобальный перехват мыши и доставка событий в целевое окно.
- Правила по процессу и полному пути исполняемого файла.
- Режимы исключений и работы только в выбранных приложениях.
- Пользовательские профили прокрутки, горячие клавиши обхода и защита полноэкранных приложений.
- Трей, автозапуск, временная пауза, темы и перенос настроек.

## Технологический стек

- **Язык и платформа:** C#, .NET `net10.0-windows10.0.19041.0`.
- **Представление:** WinUI 3, Windows App SDK, CommunityToolkit.Mvvm и CommunityToolkit.WinUI.Controls.
- **Интеграция с ОС:** SharpHook, Win32 interop, Windows Forms notify icon.
- **DI:** Microsoft.Extensions.DependencyInjection.
- **Данные:** JSON в локальном каталоге Application Data.
- **Тестирование:** xUnit.

## Архитектурные заметки

Решение применяет явную слоистую архитектуру: Domain хранит модели и инварианты, Application — сценарии и контракты, Infrastructure — адаптеры к Windows и файлу, а WinUI-проект — композицию и UI. Точка сборки зависимостей находится в `SmoothScrollModern/App.xaml.cs`.

Подробные правила находятся в [.ai-factory/ARCHITECTURE.md](ARCHITECTURE.md).

**Выбранный шаблон:** явная архитектура с техническими слоями.

## Нефункциональные требования

- Сглаживание не должно блокировать UI-поток и должно корректно прекращаться при отмене или отказе доставки.
- Изменение настроек проходит валидацию перед сохранением, импортом и созданием runtime-снимка.
- Ошибки повреждённого файла настроек не должны препятствовать запуску: файл резервируется, используются значения по умолчанию.
- Нативные вызовы и глобальный ввод изолированы в Infrastructure.
- Изменения детерминированной логики должны сопровождаться unit-тестами.
